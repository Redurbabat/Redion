# Spacing and Layout

Use spacing to communicate grouping and hierarchy.

## Scale
Prefer a coherent 4px-derived scale. Repetition matters more than a specific numeric set.

## Layout rules
- Related items sit closer than unrelated groups.
- Align to meaningful content edges.
- Reading surfaces constrain measure; work surfaces may expand.
- Dense productivity UI can use tighter spacing but must preserve target size and scanability.
- Avoid nested padding inflation from card-inside-card structures.
- Use grids when content relationships benefit from them, not because a template has columns.

Responsive layout is recomposition: reorder, collapse, overflow, switch navigation model or change presentation rather than shrinking desktop UI uniformly.
