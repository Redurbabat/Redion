# Iconography

Use a coherent icon family and familiar metaphors.

## Rules
- Icons support recognition; labels carry ambiguous meaning.
- Icon-only controls need accessible names and, for unfamiliar desktop actions, tooltips.
- Keep stroke/fill language consistent within an interface.
- Optical alignment matters more than mathematically identical bounding boxes.
- Do not mix emoji, filled glyphs, outline icons and custom 3D icons without a deliberate system.
- Destructive icons should not become playful.
- Animation is allowed for state transitions when it clarifies change; avoid continuously animated utility icons.
