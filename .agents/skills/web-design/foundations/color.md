# Color

Use semantic color roles rather than decorative hex values.

## Roles
background, surface, elevated, text-primary, text-secondary, border, accent, selected, focus, success, warning, danger, info.

## Rules
- Accent communicates action/state/brand; do not scatter it everywhere.
- State cannot rely on color alone.
- Maintain contrast across light, dark, translucent and image-backed surfaces.
- Dark mode is not simple inversion; rebalance elevation, borders and saturated accents.
- Destructive colors are reserved for destructive meaning.
- Charts need distinguishable series beyond hue where possible.

For glass surfaces, test foreground contrast against worst-case content beneath and provide a more opaque fallback.
