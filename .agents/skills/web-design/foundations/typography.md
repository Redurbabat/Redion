# Typography

Typography establishes hierarchy before decoration.

## Roles
Define semantic roles: display, page-title, section-title, body, label, metadata, code/data. Prefer project type tokens over arbitrary per-component sizes.

## Product fit
Marketing/editorial may use larger display contrast. Productivity/dashboard interfaces favor compact, stable metrics. Documentation prioritizes readable body measure and code clarity.

## Rules
- Keep body text at a comfortable line length; do not stretch prose across wide workspaces.
- Use weight, size and spacing together; avoid using color alone for hierarchy.
- Avoid excessive font weights and near-duplicate sizes.
- Preserve platform text scaling and zoom.
- Numeric/data surfaces should align numbers predictably; tabular numerals are useful when values must scan vertically.
- Truncate only when full content is recoverable.

Motion must not distort important text. During morphing transitions, prefer container geometry plus opacity/crossfade over aggressive glyph scaling.
