# Apple Platform Mode

Use for iOS, iPadOS and macOS targets or when explicitly requested. Consult current Apple HIG rather than treating copied HIG text as this project's source of truth.

## Principles
Content leads; chrome supports it. Use familiar platform navigation, safe areas, typography, input conventions and system capabilities. Translucent materials belong mainly to functional layers above content.

## iPhone
Prioritize touch, reachable actions, compact navigation, sheets and focused flows. Do not transplant desktop density.

## iPad
Treat as its own adaptive environment: touch + Pencil + keyboard/trackpad, multitasking and variable window sizes. Work surfaces can be desktop-capable while controls remain touch-aware.

## macOS
Favor windows, menus, keyboard shortcuts, sidebars/toolbars, precision pointer input and denser information architecture.

## Motion
Prefer fluid, interruptible, spatially coherent transitions. Gesture-driven motion should inherit current state/velocity when feasible.

## Materials
Use system materials/native APIs when available. Do not imitate Apple by applying blur everywhere.

## Source boundary
External Apple-HIG skills may be used as references/routing aids. Do not copy their mirrored Apple corpus into this skill.
