# Android Platform Mode

Use Material/platform conventions where they improve familiarity, but preserve the product's own design language.

Respect system navigation/insets, back behavior, dynamic type/font scaling, touch targets, dark theme and device diversity. Material 3 patterns are references, not mandatory decoration.

Prefer native-feeling sheets, app bars, navigation patterns and feedback. Test compact phones, large phones, tablets/foldables when relevant. Do not force Apple navigation or glass conventions onto Android.
