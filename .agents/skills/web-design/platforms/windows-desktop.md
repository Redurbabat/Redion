# Windows / Desktop Platform Mode

Desktop UX assumes precision pointer, keyboard, resizable windows, filesystem workflows and higher information density.

Use menus, command surfaces, sidebars, context menus, shortcuts, drag/drop and multi-window behavior when they improve repeated work. Keep hover as enhancement, not sole access.

Windows material concepts such as Mica/Acrylic can inspire hierarchy when targeting Windows, but do not mix platform materials indiscriminately. Preserve clear focus, window resizing behavior and high-contrast support.
