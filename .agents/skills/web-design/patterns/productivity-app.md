# Productivity / Desktop-like App Pattern

## Goal
Optimize repeated workflows, information density, direct manipulation and keyboard efficiency.

## Shell
Stable app shell -> primary navigation -> optional context sidebar -> work surface -> contextual controls/status.

## Controls
Frequent actions remain reachable. Secondary options appear contextually. Support shortcuts and command palette when command volume justifies it.

## Workspace
The user's object/document/canvas dominates. Chrome should not consume unnecessary space.

## Motion
Level 1–2. Springs/proximity effects may be used in specialized docks or direct-manipulation controls, not across the entire shell.

## Avoid
Marketing-style hero sections, giant cards, excessive modal workflows, tool options permanently occupying space when irrelevant.
