# Documentation / Knowledge Pattern

## Goal
Help users find, understand and navigate information quickly.

## Structure
Global navigation/search -> local hierarchy -> readable content -> in-page navigation where useful -> related/next content.

## Typography
Optimize line length, headings, code blocks, tables and callouts for sustained reading. Anchor headings for deep links.

## Search
Results should expose title, context/snippet and location. Keyboard navigation is valuable for frequent users.

## Motion
Level 0–1. Orientation beats spectacle.

## Avoid
Narrow content hidden inside giant decorative shells, excessive cards, animated backgrounds, poor heading hierarchy, navigation that resets reading context.
