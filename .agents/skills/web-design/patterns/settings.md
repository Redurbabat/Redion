# Settings Pattern

Settings optimize findability, comprehension and safe change.

Group by user mental model. Use search for large settings surfaces. Prefer immediate-save for reversible low-risk preferences; use explicit Save when changes form a transaction or have significant consequences.

Show current state clearly. Destructive/account actions belong in a clearly separated area. Explain dependencies and disabled states.

Desktop can use sidebar categories; mobile commonly uses hierarchical lists/detail screens. Preserve deep links where useful.
