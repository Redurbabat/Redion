# Adaptive App Shell

Do not build one desktop layout and shrink it.

## Desktop
High density, precision pointer, keyboard shortcuts, persistent navigation/inspectors, resizable regions and multi-window potential.

## Tablet
Treat width and input as dynamic. Support touch plus optional stylus/keyboard/trackpad. Sidebars may become collapsible/overlay depending on window size. Preserve a large work surface.

## Phone
Prioritize focused tasks, one-handed reach and progressive disclosure. Convert persistent inspectors to sheets/detail screens and large toolbars to compact contextual controls.

## Adaptation decision
Respond to available space, input modality, task and platform conventions—not device name alone. A tablet in split view may need a phone-like composition; a large foldable may support two panes.

Keep information architecture stable even when presentation changes.
