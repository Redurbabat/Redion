# Onboarding Pattern

Teach only what is needed to reach first value.

Prefer progressive onboarding over long tours. Ask permissions at the moment their benefit is understandable. Allow skipping nonessential education.

For complex productivity tools, combine a useful empty state, sample/demo content where truthful, contextual tips and command discovery. Do not block experienced users with mandatory carousel tutorials.

Celebrate completion proportionally; do not add confetti to serious workflows by default.
