# Command Center / Command Palette

A command center accelerates known actions; it does not replace understandable navigation.

## Anatomy
trigger -> query -> ranked commands/results -> keyboard selection -> execution/secondary detail.

Support keyboard-first operation, visible shortcut hints where useful, fuzzy matching and recent commands only when real data exists. Group commands by semantic domain rather than decorative categories.

Differentiate navigation, action, search result and destructive command. Destructive commands need clear labeling and appropriate confirmation.

Opening/closing should be fast. A restrained elevated/translucent material is appropriate because the palette is transient and context should remain perceptible.
