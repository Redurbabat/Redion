# Landing / Marketing Page Pattern

## Goal
Communicate value quickly, establish trust, and guide a visitor toward a meaningful conversion.

## Typical flow
Header/navigation -> hero/value proposition -> evidence/proof -> capabilities/benefits -> product demonstration -> trust/objections -> CTA -> footer.

This is a menu of sections, not a mandatory template.

## Hero
Answer: what is it, for whom, why it matters, and what should I do next? Use one dominant CTA and an optional secondary path. Visuals should demonstrate product/brand rather than fill space.

## Motion
Usually level 1–2. Level 3 only for creative/showcase brands. Scroll motion should reinforce narrative, not block reading.

## Avoid
Generic gradient blobs, meaningless dashboard mockups, ten feature cards, excessive logo marquees, vague superlatives, giant empty hero height, repeated CTAs with equal weight.
