# Context Menus

Context menus expose actions for a selected object/location without permanently occupying space.

Use right-click/secondary click on desktop where expected. Touch needs a discoverable alternative such as long press or overflow menu; essential actions must not exist only in a hidden gesture.

Order actions by task frequency and grouping. Separate destructive actions. Disable unavailable actions with an understandable reason when useful.

Open near the invocation point while remaining on-screen. Keyboard invocation must anchor sensibly to the focused element. Menus should dismiss predictably on selection, Escape, outside interaction or context loss.
