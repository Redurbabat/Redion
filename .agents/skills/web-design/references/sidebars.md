# Sidebars and Inspectors

Sidebars support persistent navigation or contextual detail.

## Navigation sidebar
Use for many destinations, deep hierarchy or repeated desktop workflows. Preserve selected state and allow sensible collapse when space is constrained.

## Inspector
Use for properties of the current selection/context. Update content when selection changes; do not mix unrelated global settings into a contextual inspector.

## Responsive
Desktop can keep sidebars persistent. Tablet may overlay/collapse them depending on window width. Phone usually needs another navigation/presentation model.

Resizable sidebars should have usable min/max widths and preserve user preference when appropriate.
