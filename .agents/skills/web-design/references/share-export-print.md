# Share, Export and Print

Expose only actions the product can actually complete.

## Separate concepts
Share sends or hands off content. Export creates a representation/file. Print targets paper/PDF print pipelines. Copy link requires a real address and permissions.

## UI
Choose actions from actual capability and current content type. Do not show decorative share destinations that are unavailable. Long exports need progress, cancellation when supported and truthful completion.

Export/print previews must include the content users expect, including annotations/overlays that are part of the document. Test generated output, not only the on-screen canvas.

Platform share sheets are preferable when they provide the expected native destinations. Provide explicit fallback where unavailable.
