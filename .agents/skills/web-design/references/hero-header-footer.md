# Hero, Header and Footer

## Hero
A hero exists to establish value, context and a next action. It is not mandatory for utility/productivity screens.

Good hero ingredients: clear proposition, supporting evidence/visual, one dominant action, optional secondary action. Motion can demonstrate product behavior but must not delay comprehension.

## Header
Keep global navigation stable and recognizable. Sticky headers may compact on scroll, but avoid constant distracting transformation. Marketing headers can be more expressive; app shells should be quieter.

## Footer
Use for secondary navigation, legal/support/contact and closure. Do not duplicate the entire site without hierarchy.

Avoid oversized empty hero sections, fake social proof, autoplay spectacle and decorative 3D that competes with the value proposition.
