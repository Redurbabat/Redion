# Search and Command Palette

## Search
Search finds content. Provide useful scope, clear query state, keyboard submit/clear, loading, no-results and error states. Results should show enough context to distinguish similar items.

## Command palette
A command palette executes or navigates to actions quickly. It complements visible UI; it must not become the only way to discover core features.

## Anatomy
Input -> grouped/ranked results -> icon -> title -> context -> optional shortcut/action hint.

## Keyboard
Open shortcut when appropriate, arrow navigation, Enter to activate, Escape to close, predictable focus restoration.

## Ranking
Prefer contextual relevance and recent/frequent actions only when the product legitimately has that data. Never fabricate personalization.

## Avoid
Mixing content search and destructive commands without clear distinction; hidden core navigation; overly large modal chrome.
