# Tabs and Accordions

Tabs switch peer views within the same context. Accordions reveal optional sections in a vertical flow.

## Tabs
Keep labels short and stable. Selected state must be obvious beyond color. Avoid horizontal tab overflow without a strategy. Do not use tabs as a substitute for global navigation.

## Accordions
Use when users benefit from scanning headings before expanding detail. Do not hide critical primary content merely to make a page look shorter.

Motion should reinforce expansion/collapse without making repeated navigation feel slow. Preserve focus and keyboard behavior.
