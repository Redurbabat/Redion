# Contextual Action Rails

A quiet application shell may expose a very small number of context actions near the work surface.

## Selection
Promote an action only when it is frequent, context-specific, safe and materially faster than opening a tool/menu. Examples can include Annotate while reading or New within a collection.

Do not promote actions merely to fill empty chrome. Zero direct context actions is valid when the workspace benefits from calmness.

## Adaptation
Desktop rails can expose precision-oriented actions. Tablet may use floating controls. Phone usually folds them into a compact toolbar/sheet.

Measure whether promoted actions compete with navigation or document content. Context actions disappear when their context disappears.
