# Haptics and Sound

Use sensory feedback as reinforcement, never the only signal.

## Haptics
Appropriate for meaningful selection, snap, boundary, successful commit or warning where platform conventions support it. Avoid firing haptics on every hover or scroll tick.

## Sound
Use only when product context benefits and users can control it. UI sounds should be short, non-startling and semantically consistent. Do not autoplay decorative sound on websites.

Respect OS/user preferences and silent/reduced-feedback contexts. Pair important haptic/audio events with visible state.
