# Navigation

## Choose from information architecture
- small marketing site -> top navigation
- large content site -> global header + structured secondary navigation
- dashboard -> sidebar/rail
- desktop productivity -> activity rail + optional contextual sidebar
- deep hierarchy -> tree + breadcrumbs where useful
- many commands -> command palette supplements visible navigation
- mobile primary destinations -> bottom/compact navigation when appropriate

## States
Current location must be obvious without relying only on color. Hover and focus are distinct from selected/current.

## Behavior
Preserve context where possible. Do not move primary navigation unpredictably between pages. Collapsing navigation must retain labels through tooltip or accessible name.

## Overflow
Prefer deliberate More/overflow or horizontal patterns for tools. Do not squeeze labels until unreadable.

## Avoid
Hamburger menus on wide desktop without reason, five competing nav systems, tabs used as site navigation, hidden essential destinations, animation that delays navigation.
