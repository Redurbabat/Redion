# File Browser

File interfaces optimize recognition, hierarchy and safe operations.

Use list/table for dense metadata and grid for visual assets. Support search/filter/sort only when dataset size warrants them. Breadcrumbs/tree navigation help deep hierarchy.

Common actions: open, rename, move, duplicate, share/export, delete, restore where applicable. Destructive operations must communicate scope.

Drag/drop should expose destination clearly. Upload/download/sync need progress and failure recovery. Never fake filesystem access or synchronization.
