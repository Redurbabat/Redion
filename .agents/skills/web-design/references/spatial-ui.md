# Spatial UI

Spatial UI uses depth, position and motion to communicate relationships.

Use spatial models for canvases, maps, node graphs, 3D editors, immersive media and object-centric exploration. Ordinary forms/settings rarely need them.

Maintain orientation through stable landmarks, predictable camera behavior and reversible navigation. Keep UI controls legible in screen space when perspective would harm readability.

Avoid excessive depth layers. Occlusion must not hide essential controls. Provide non-spatial alternatives for essential information and reduced-motion users.
