# Mobile Navigation

Design for reachable, focused flows rather than shrinking desktop navigation.

Use bottom navigation for a small set of primary destinations when appropriate; top bars for context/actions; drawers/menus for secondary destinations; sheets for contextual choices.

Preserve platform back behavior. Avoid hiding primary actions behind repeated overflow. Respect safe areas, software keyboard and dynamic text.

One-handed reach matters for frequent phone actions. Tablet navigation should adapt to available width rather than pretending to be a large phone.
