# Special Buttons and High-Craft Controls

Special controls are earned by frequency, importance, brand expression or direct manipulation. Standard actions should remain standard.

## Variants
- Primary action: strongest local emphasis.
- Toolbar icon: compact, immediate, tooltip/accessibility name.
- Toggle/segmented: persistent state selection.
- Floating action: only when one cross-context action truly dominates.
- Glass control: floating over content where context beneath matters.
- Magnetic/proximity control: expressive desktop pointer environments only.
- Morphing control: when the same action changes state/form and continuity helps comprehension.
- Hold-to-confirm: rare high-consequence or continuous action, never a substitute for clear confirmation.

## Interaction recipe
Default -> hover/focus -> press -> action -> success/loading/state change.
Press feedback should be immediate. Typical scale is subtle (~0.97–0.99); stronger compression is reserved for tactile/expressive controls. Do not make text visibly wobble.

## Magnetic behavior
Use only with a pointer, with small attraction distance and bounded displacement. The hit target must remain stable and keyboard/touch behavior conventional.

## Glass button
Use restrained translucent material, crisp label/icon, edge definition and strong contrast. On unsupported/reduced-transparency environments use an opaque surface.

## Destructive
Never use playful bounce, magnetic attraction, celebratory particles or ambiguous color for destructive actions.

## Rule
A special button must still behave like a button: predictable activation, focus, accessible name, disabled/loading state, and no hover-only functionality.
