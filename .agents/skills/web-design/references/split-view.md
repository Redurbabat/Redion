# Split View

Split views let two related surfaces remain simultaneously visible.

Use when comparison, reference, navigation+content, inspector+canvas or source+preview benefits from persistent coexistence.

The divider is an interactive control: provide pointer drag plus keyboard adjustment and accessible separator semantics. Define min/max constraints from usable content, not arbitrary percentages.

During resize, prioritize direct response. Expensive children may temporarily simplify rendering, but final content must settle immediately after release.

On narrow screens, recombine into tabs, sheets or sequential navigation rather than crushing both panes.

Remember user sizing only when that preference is meaningful and recoverable.
