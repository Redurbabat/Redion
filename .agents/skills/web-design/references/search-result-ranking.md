# Search Result Ranking

Search ranking should be explainable from legitimate signals and stable enough to build user trust.

Possible signals: textual relevance, exact/prefix match, current context, recency and explicit user favorites. Frequency/personalization may be used only when the product actually records that data.

Do not fabricate “recent” or “frequent” ordering.

Commands and content results can share a surface, but distinguish their type and action. Query changes should not cause distracting reordering unrelated to relevance.

Preserve keyboard selection sensibly as results update. Empty, loading, partial/offline and error states require distinct treatment.
