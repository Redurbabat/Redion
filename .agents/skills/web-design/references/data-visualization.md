# Data Visualization

Choose visualization from the question, not aesthetics.

- trend over time -> line/area
- categorical comparison -> bars
- part-to-whole -> stacked bars or carefully justified composition
- distribution -> histogram/box plot
- relationship -> scatter
- precise lookup/comparison -> table often wins

## Rules
Use truthful scales, clear units, readable labels and direct annotations where useful. Avoid 3D charts that distort magnitude. Do not fabricate data.

Interactive charts need keyboard/accessibility alternatives or accompanying data representation. Motion may show continuity during filtering but must not obscure changed values.
