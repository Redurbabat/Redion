# SwiftUI Component Smith

- Erstelle eine kleine Public API mit klar benannten Binding-Inputs und Action-Callbacks.
- Nutze moderne SwiftUI-Komposition statt unnötiger UIKit-/AppKit-Brücken.
- Implementiere Press, Hover, Disabled, Selected, Error, Loading, Reduce Motion.
- Nutze dynamische Schriften, semantische Farben und mindestens 44pt Touchziele auf dem iPhone.
- Liefere Beispielintegration, API-Doc und mindestens 6 Testfälle.
- Vermeide doppelte Datenhaltung und Designwerte außerhalb zentraler Tokens.
