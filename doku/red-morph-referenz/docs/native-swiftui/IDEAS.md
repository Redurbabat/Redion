# Native SwiftUI: Kreative App-Ideen und Interaktionen

- **Double Dock Studio:** Erste Dockleiste wechselt Arbeitsbereich, zweite Dockleiste zeigt PDF-/Notiz-/Design-Werkzeuge. Öffnen per Hochziehen oder Pfeil.
- **Magnetic Action Palette:** Floating-Button entfaltet ein modales Radialmenü; aktiviertes Werkzeug bleibt tastaturbedienbar.
- **Elastic Document Shelf:** Dokumente werden beim Verschieben wie physische Karten sortiert, mit Undo.
- **Motion Recipe Lab:** Karte zeigt eine Animation; Slider verändern Dauer, Bounce und Intensität in Echtzeit.
- **Design Vault:** Screenshots und Farbpaletten einsammeln, mit Tags, Suche und matchedGeometryEffect-Detailansicht.
- **PDF Markup Deck:** Kontextleiste über dem Dokument bei Auswahl; Annotationen bleiben mit PDFKit erhalten.
- **Smart Note Canvas:** Note-Karten anpinnen, zusammenziehen, als Markdown/PDF exportieren.
- **Adaptive Mac Inspector:** Auswahl im Canvas morphiert in einen rechten Inspector; macOS-Tastaturfokus bleibt erhalten.
- **Command Dock:** Auf dem Mac mit ⌘K Werkzeug suchen, auf dem iPhone per sichtbarem Suchbutton.
- **Haptic State Machine:** Deutliche, sparsame Haptik bei Ausrichtung, Snap, Erfolg.
- **Progressive Detail:** Primäraktion sofort sichtbar, Expertenoptionen erst im zweiten Dock.
- **Shared Element Search:** Suchtreffer animiert von Miniatur auf die Detailoberfläche.
- **Timeline Scrubber:** Animationen vor/zurück scrubben und Geschwindigkeitskurven verstehen.
- **Card Stack Physics:** Kleine Karten-Stapel mit Snap-Punkten, ohne unkontrollierte Endlos-Animationen.
- **Inspector Layers:** Mehrstufiger Werkzeugbereich statt modalem Dialog-Stapel.

Zu jeder Idee: User Journey, States/Errors, Accessibility, iOS/macOS-Eingabe, Persistenz, Undo, Performance und SwiftUI-Tests definieren.
